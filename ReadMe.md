This project was created by Andrew Ralph a student at Farmingdale State College. It is a simple RPG game created in Java using the Swing library for the GUI.

The game is still in devlopment and below will be a list of features that are currently being worked on and will be added in the future.

Current Features:
- 1 class (Warrior)
- 1 weapon (Sword)
movement implemented with WASD keys 

future features:
- 3 more classes (Archer, Mage, Priest)
- 3 more weapons (Bow, Staff, Mace)
- 10 new enemies 
- Health and Mana system
- Inventory system
- Leveling system
- Quests
- Boss fights
